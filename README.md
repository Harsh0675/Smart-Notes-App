# Smart Notes App

A modern offline Android notes app built with Kotlin.

## Features
- Create, edit and delete notes
- Instant search
- Pin and favorite notes
- Permanent dark mode
- Lavender, Ocean, Forest, Sunset and Rose accent themes
- Personal image theme
- 4-digit PIN lock
- PIN protected with Android Keystore AES-GCM encryption
- Custom Smart Notes launcher icon
- Fully offline; no internet required

## Version
1.1.0

## Build
Open the project in Android Studio or build with Gradle using an Android SDK installation.

Package: `com.harsh.smartnotes`
